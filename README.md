## 👋 About Me

I'm a **Cloud DevOps Engineer with 5+ years of experience** building,
automating, securing, and operating cloud infrastructure and delivery
platforms. My primary focus is **Microsoft Azure, Kubernetes,
Infrastructure as Code, CI/CD, and DevSecOps**.

I enjoy turning complex operational workflows into repeatable,
observable, and secure engineering systems---from infrastructure
provisioning and deployment pipelines to container orchestration and
production troubleshooting.

-   ☁️ **Cloud:** Azure-focused, with foundational AWS experience
-   🏗️ **Infrastructure as Code:** Terraform, reusable modules, remote
    state, and environment-based deployments
-   🚀 **Delivery:** Azure DevOps, GitHub Actions, Jenkins, and CI/CD
    automation
-   🐳 **Containers:** Docker, Kubernetes, and Azure Kubernetes Service
    (AKS)
-   🔐 **DevSecOps:** Security scanning, secrets management, least
    privilege, and policy-aware delivery
-   📈 **Operations:** Monitoring, logging, troubleshooting,
    reliability, and incident response
-   🌱 **Currently exploring:** MLOps, LLM platforms, and AI-enabled
    engineering workflows

> **My engineering principle:** automate the repeatable, secure the
> default, observe everything important, and make recovery predictable.
